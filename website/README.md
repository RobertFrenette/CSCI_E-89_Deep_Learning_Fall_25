# AI Agent Insure — Landing Page

A modern, single-page marketing landing page built using **React**, **TypeScript**, and **Vite**.  
Designed for the fictional insurance company **AI Agent Insure**, which provides insurance services for organizations building and deploying Agentic AI systems.

---

## 🚀 Features

- **React 18 + TypeScript + Vite** for a fast, modern dev environment  
- Fully responsive **dark-mode UI** with modern gradient styling  
- Sticky navigation bar with anchor-based scrolling  
- Prominent **hero section** with actionable CTAs  
- Product summary cards styled for clarity and impact  
- “Why now” and “How it works” sections to communicate value  
- A styled **contact form** with validation-ready structure  
- Clean component architecture (single-page)

## 🛠️ Installation

After downloading/unzipping the project:

```bash
cd ai-agent-insure-landing
npm install
```

---

## ▶️ Running the Development Server

```bash
npm run dev
```

This will start a local Vite server (usually at **http://localhost:5173**).
